The Threshold

julia set · z ← z² + c · c wanders
c = −0.745 + 0.113i

Every point in the frame is asked the same question: if you keep folding into yourself, do you stay, or do you fly apart? The dark interior is the set of points that stay bound forever. The copper and blue filaments are the ones that almost stayed. c is the seed, and it never stops moving.

Drag on the canvas to hold c where you want it. Let go and it wanders again. Right-click or long-press to save a frame.
